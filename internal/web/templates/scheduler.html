Collection scheduler

Scheduler execution limits

Only explicitly authorized schedules run. Manual and scheduled collection share five active asset slots, one collection per asset and 32 waiting requests. Scheduled pending work is limited to 32 profiles. One active application process is enforced. Lag and collection failures do not evaluate asset health.

Execution controls

Global pause: {{.Scheduling.Status.Paused}} · emergency stop: {{.Scheduling.Status.Stopped}}. Pause blocks new scheduled work and lets running work finish. Emergency stop also cancels running manual collection and blocks new manual requests. Stop remains in force after restart until explicitly released.
